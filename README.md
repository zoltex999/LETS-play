## 🛠️ Installation

### 📦 Prerequisites

- 🟢 Node.js v18+ (or v12, or v24, whatever)
- 🐍 Python 3 (we don't use it but it's better to have it)
- ☕ Java
- 🧘 Patience
- 💾 2 GB RAM recommended, 64 GB required

### ⚙️ Steps

1. 📥 Clone the repo

```bash
git clone https://github.com/user/lets-play.git
cd lets-play
cd lets-play
```

2. 📦 Install dependencies 📦

```bash
npm install
pip install -r requirements.txt
cargo build
npm install
```

3. 🔑 Create a `.env` file 🔑

```env
API_KEY=your_api_key_here
SECRET=do_not_share
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxx
GAME=true
```

4. 🚀 Launch the game 🚀

```bash
npm run start
# if that doesn't work:
npm run dev
# if that still doesn't work:
sudo npm run please
```

5. 🎉 Profit 🎉
